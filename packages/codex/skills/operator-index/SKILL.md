# Operator Project Index Setup

1. Run `operator-helper index init` once. If Helper cannot start, help the user repair it, verify the repair, ask them to invoke `$operator-index` again, and stop.
2. Follow the emitted Project Index Setup guide with the user, including when inspection reports failures. Preserve and address the reported failure details.

Use Helper output as working context. Do not reproduce it for the user or reimplement Helper logic.
